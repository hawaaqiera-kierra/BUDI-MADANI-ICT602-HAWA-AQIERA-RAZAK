# BUDI-MADANI-ICT602-HAWA-AQIERA-RAZAK
This Android application is calculates the total petrol cost and BUDI MADANI subsidy savings.<br>

## Features included<br>
- Select petrol type (RON95/RON97/Diesel)<br>
- Enter petrol price per liter (RM)<br>
- Select the fuel usage using SeekBar<br>
- Click eligibility status<br>
- Check eligibility automitically (RON95 only)<br>
- Calculate total cost, BUDI rebate and savings<br>
- Has two page which is Home page (BUDI Calculator) and About page by clicking the menu<br>
